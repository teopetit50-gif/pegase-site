Contrat : l'inventaire de l'écran d'avant (`docs/refonte-metiers/daliro.md`, blocs B01-B27, fenêtres F01-F34, page P01,
gestes G01-G63, entrées E01-E17, D01-D03, R01-R08). Nouvelles pages : `docs/refonte-metiers/DECOUPAGES.md` (neuf

(`components/espace2/daliro/*`, `components/espace/daliro/ChantierVue.tsx` et ses `sections`), puis vérifiée dans
l'application.

**Comment la preuve a été faite.** `npm install` puis `npm run dev` dans le conteneur, sans session ni variable
Supabase : toutes les pages s'ouvrent en « Données d'exemple » (le ruban est vérifié avant chaque clic). Playwright
(Chromium sans tête, 1440 × 900) ouvre chaque page, cherche le bouton par son nom accessible exact, ouvre chaque
fenêtre, lit son titre et la referme par Échap ; aucun clic qui valide, envoie, signe ou supprime. Un geste qui
n'apparaît que dans un état absent de l'exemple est noté « ÉTAT ABSENT DE L'EXEMPLE », avec la ligne de code qui le
porte et la section qui la monte sur la nouvelle page. L'écran d'avant (`/espace2/daliro?ancien=1`) a été relevé de la
même façon pour comparer : il ne montre aucun bouton que la nouvelle fiche n'ait pas, sur les deux chantiers
d'exemple. Exemple : Résidence Les Tilleuls (ouvert, `…d001`) et Maison Rolland — extension (en préparation, `…d002`).
